  ~2,000 transaction records and calculating KPIs including revenue,
  profit margin, and average order value.
- Developed an interactive Streamlit dashboard with filterable charts
  for category, regional, and customer analysis; deployed on Streamlit
  Community Cloud.
- Documented the full workflow — data cleaning, NumPy-based analysis,
  and business insights — in a Jupyter notebook and public GitHub

## Detailed Version (4–5 bullets)

- Designed and built a complete Data Analyst portfolio project analyzing
  retail sales and customer data using Python and NumPy, covering data
  cleaning, KPI calculation, filtering, aggregation, and visualization.
- Cleaned a ~2,000-row dataset containing missing values, duplicate
  records, and inconsistent formatting, reducing data-quality issues
  before analysis.
- Applied NumPy for vectorized calculations, Boolean-mask filtering, and
  group-style aggregation (conceptually equivalent to SQL `GROUP BY`),
  calculating KPIs such as total revenue, profit margin, and average
  order value.
- Built six Matplotlib visualizations covering sales trends, category
  and regional performance, and top products, each tied to a specific
  business question.
- Developed and deployed an interactive Streamlit dashboard with
  region/category/customer-type filters, and published the full project
  — notebook, source code, and documentation — on GitHub.
